# Verification examples

Load only when the scenario is relevant. These illustrate the verification standard, not required checks for every run.

- **Cleanup:** protected consumers exist before deletion. Check survival and retained-tool reproduction; unsafe deletion should fail. Creating protected assets afterward proves nothing.
- **Sanitization:** correct output can still retain an authorization header. Inspect retained payloads independently; redaction preserves claim-relevant values, attribution and limits.

Prefer relevant proven methods from run knowledge; adapt examples to the approved claim.
